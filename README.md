# CartPole RL Experiments

Comparing reinforcement learning algorithms and hyperparameters on the CartPole-v1 environment.

## Goal
Understand how different RL algorithms and hyperparameters affect learning on a classic control task.


## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

```


## Tech Stack

- PyTorch 2.0
- Gymnasium (OpenAI Gym)
- Matplotlib for visualization
- NumPy for data processing
